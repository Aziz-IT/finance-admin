# Finance admin

A single-page personal finance dashboard: salary, debts, obligations, budget, an automatic debt payment plan with a balance chart and schedule.

Your figures are saved only in the browser you use. Nothing is sent to a server. Use Settings → Export JSON for backups.

## Run
Open `index.html` in any browser.

## Publish
GitHub Pages: Settings → Pages → Deploy from branch `main`, folder `/ (root)`.
